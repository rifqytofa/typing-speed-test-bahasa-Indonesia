# Typing Speed Test Bahasa Indonesia

Typing Speed Test online gratis untuk mengukur **kecepatan mengetik (WPM)** dan **akurasi mengetik** menggunakan teks Bahasa Indonesia.

## Fitur

- Tes mengetik Bahasa Indonesia
- Pilihan waktu 1 menit, 3 menit, atau tanpa batas
- Perhitungan WPM dan akurasi
- Tombol Stop untuk langsung melihat hasil
- Papan peringkat online
- Login Google dan anonim melalui Supabase
- Bisa digunakan di HP maupun komputer
